LIS (LONGEST INCREASING SUBSEQUENCE) VARIANTS
============================================

1. Longest Increasing Subsequence (LIS)
---------------------------------------
Problem:
Find length of longest strictly increasing subsequence.

Examples:
- LeetCode 300

Approaches:
- O(N²) DP
- O(N log N) Binary Search (Patience Sorting)

Must Know.

--------------------------------------------------

2. Print / Reconstruct LIS
--------------------------
Problem:
Return actual LIS sequence.

Concept:
- Parent array
- Backtracking

Very common follow-up.

--------------------------------------------------

3. Number of Longest Increasing Subsequences
--------------------------------------------
Problem:
Count how many LIS exist.

Examples:
- LeetCode 673

Concept:
Maintain:
- len[i]
- cnt[i]

Important Interview Question.

--------------------------------------------------

4. Longest Divisible Subset
---------------------------
Problem:
Find largest subset where:

nums[i] % nums[j] == 0

Examples:
- LeetCode 368

Concept:
LIS-style DP after sorting.

Very common.

--------------------------------------------------

5. Largest Increasing Subsequence Sum
-------------------------------------
Problem:
Maximum sum among all increasing subsequences.

Examples:
- GFG Maximum Sum Increasing Subsequence

DP:
dp[i] = best sum ending at i

Classic Variant.

--------------------------------------------------

6. Longest Bitonic Subsequence
------------------------------
Problem:
Increasing then decreasing.

Examples:
- GFG Longest Bitonic Subsequence

Concept:
LIS from left
LIS from right

Answer:
lis[i] + lds[i] - 1

Very Popular.

--------------------------------------------------

7. Minimum Deletions to Make Array Sorted
-----------------------------------------
Problem:
Remove minimum elements so remaining array is sorted.

Formula:

Answer = n - LIS

Classic Interview Question.

--------------------------------------------------

8. Russian Doll Envelopes
-------------------------
Problem:
Maximum envelopes nested inside each other.

Examples:
- LeetCode 354

Concept:
Sort + LIS

Very Famous.

--------------------------------------------------

9. Longest Pair Chain
---------------------
Problem:
Maximum chain of pairs.

Examples:
- LeetCode 646

Concept:
Sort + LIS/Greedy

Frequently Asked.

--------------------------------------------------

10. Increasing Triplet Subsequence
----------------------------------
Problem:
Does there exist LIS length >= 3 ?

Examples:
- LeetCode 334

Concept:
Greedy

O(N)

Very Common OA Question.

--------------------------------------------------

11. Longest Arithmetic Subsequence
----------------------------------
Problem:
Longest subsequence with constant difference.

Examples:
- LeetCode 1027

Concept:
DP + HashMap

Popular Interview Variant.

--------------------------------------------------

12. Longest Arithmetic Subsequence of Given Difference
------------------------------------------------------
Examples:
- LeetCode 1218

Concept:
HashMap DP

Easy Variant of #11.

--------------------------------------------------

13. Longest Fibonacci-like Subsequence
--------------------------------------
Examples:
- LeetCode 873

Concept:
DP + Hashing

Moderately Common.

--------------------------------------------------

14. Maximum Length Chain of Pairs
---------------------------------
Examples:
- GFG
- Similar to Pair Chain

Concept:
Sorting + LIS

--------------------------------------------------

15. Box Stacking
---------------
Problem:
Maximum stack height.

Concept:
3D LIS

Classic DP Problem.

--------------------------------------------------

16. Building Bridges
-------------------
Problem:
Maximum non-crossing bridges.

Concept:
Sort one side
Apply LIS on other side

Classic LIS Reduction.

--------------------------------------------------

17. Circus Tower
----------------
Problem:
Height and Weight ordering.

Concept:
2D LIS

Very famous interview problem.

--------------------------------------------------

18. LIS in 2D / 3D
------------------
Pattern:

Sort first dimension.
Run LIS on second dimension.

Examples:
- Envelopes
- Bridges
- Towers
- Box Stacking

Very Important Pattern.

--------------------------------------------------

19. Longest Non-Decreasing Subsequence
--------------------------------------
Difference:

arr[j] <= arr[i]

instead of

arr[j] < arr[i]

Sometimes appears in OAs.

--------------------------------------------------

20. K-Increasing Array
----------------------
Examples:
- LeetCode 2111

Concept:
LNDS (Longest Non-Decreasing Subsequence)

Advanced Variant.
