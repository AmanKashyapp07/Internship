# Priority Queue & Intervals
## Master Interview & OA Guide (C++)

---

## How to Use This Guide

Priority Queue (heap) and Interval problems are separate topics but they
intersect constantly — most hard interval problems require a heap to track
active intervals efficiently. Learn them in order: intervals first, then
heap-augmented interval problems.

---

## Master Decision Tree

```
Does the problem involve ranges [start, end]?
  YES ->
    Merge / combine overlapping ranges?         -> Merge Intervals
    Insert a new range into existing sorted set? -> Insert Interval
    How many overlap at the same time?           -> Sweep Line / Min Heap
    Schedule tasks, rooms, or machines?          -> Greedy + Min Heap
    Remove minimum intervals to make non-overlap?-> Greedy (sort by end)

Does the problem involve repeatedly finding the k-th largest/smallest?
  YES -> Max Heap or Min Heap

Does the problem need the median of a stream?
  YES -> Two Heaps (max heap + min heap)

Does the problem involve k sorted lists or k pointers?
  YES -> Min Heap of size k

Does the problem ask for k largest, k most frequent, k closest?
  YES -> Heap of size k (opposite type to what you want)

Does the problem involve scheduling with deadlines or cooldowns?
  YES -> Greedy + Max Heap (by frequency or priority)
```

# PART 1: PRIORITY QUEUE (HEAP)

## C++ Heap Syntax

```cpp
// Max heap (default) — largest element at top
priority_queue<int> maxPQ;

// Min heap — smallest element at top
priority_queue<int, vector<int>, greater<int>> minPQ;

// Custom comparator (min heap by first element of pair)
priority_queue<pair<int,int>, vector<pair<int,int>>, greater<pair<int,int>>> pq;

// Lambda comparator
auto cmp = [](pair<int,int>& a, pair<int,int>& b) {
    return a.first > b.first; // min heap by first
};
priority_queue<pair<int,int>, vector<pair<int,int>>, decltype(cmp)> pq(cmp);

// Operations — all O(log n)
pq.push(x);
pq.pop();
pq.top();      // peek without removing
pq.empty();
pq.size();
```

## Pattern 1A: Kth Largest / Smallest

Keep a heap of size k. When heap exceeds size k, pop. The top of the
heap is your answer.

```cpp
// LC 215. Kth Largest Element in an Array
// Min heap of size k: top is the kth largest
int findKthLargest(vector<int>& nums, int k) {
    priority_queue<int, vector<int>, greater<int>> minPQ; // min heap
    for (int x : nums) {
        minPQ.push(x);
        if (minPQ.size() > k)
            minPQ.pop(); // remove the smallest; keep top k largest
    }
    return minPQ.top(); // smallest of the top k = kth largest
}
```

```cpp
// LC 973. K Closest Points to Origin
// Min heap by distance, keep top k
vector<vector<int>> kClosest(vector<vector<int>>& points, int k) {
    // Max heap by distance — evict farthest when size > k
    auto cmp = [](vector<int>& a, vector<int>& b) {
        return a[0]*a[0] + a[1]*a[1] < b[0]*b[0] + b[1]*b[1];
    };
    priority_queue<vector<int>, vector<vector<int>>, decltype(cmp)> maxPQ(cmp);
    for (auto& p : points) {
        maxPQ.push(p);
        if (maxPQ.size() > k)
            maxPQ.pop();
    }
    vector<vector<int>> ans;
    while (!maxPQ.empty()) {
        ans.push_back(maxPQ.top());
        maxPQ.pop();
    }
    return ans;
}
```

**The Rule:**
- Want k largest  -> use min heap of size k (top = kth largest)
- Want k smallest -> use max heap of size k (top = kth smallest)

## Pattern 1B: Top K Frequent

```cpp
// LC 347. Top K Frequent Elements
vector<int> topKFrequent(vector<int>& nums, int k) {
    unordered_map<int, int> freq;
    for (int x : nums) freq[x]++;

    // Min heap by frequency — keep top k most frequent
    priority_queue<pair<int,int>, vector<pair<int,int>>, greater<pair<int,int>>> minPQ;
    for (auto& [val, cnt] : freq) {
        minPQ.push({cnt, val});
        if (minPQ.size() > k)
            minPQ.pop();
    }

    vector<int> ans;
    while (!minPQ.empty()) {
        ans.push_back(minPQ.top().second);
        minPQ.pop();
    }
    return ans;
}
```

```cpp
// LC 692. Top K Frequent Words
// Same pattern but lexicographic tiebreak
vector<string> topKFrequent(vector<string>& words, int k) {
    unordered_map<string, int> freq;
    for (auto& w : words) freq[w]++;

    // Min heap: lower freq first; for equal freq, lexicographically larger first
    // (so the "worst" candidate sits at top and gets evicted)
    auto cmp = [](pair<int,string>& a, pair<int,string>& b) {
        if (a.first != b.first) return a.first > b.first;
        return a.second < b.second; // lexicographically larger = worse
    };
    priority_queue<pair<int,string>, vector<pair<int,string>>, decltype(cmp)> pq(cmp);
    for (auto& [w, cnt] : freq) {
        pq.push({cnt, w});
        if (pq.size() > k)
            pq.pop();
    }
    vector<string> ans;
    while (!pq.empty()) {
        ans.push_back(pq.top().second);
        pq.pop();
    }
    reverse(ans.begin(), ans.end());
    return ans;
}
```

## Pattern 1C: Merge K Sorted Lists / Arrays

Use a min heap storing one element per list. Always pop the smallest,
push the next element from that same list.

```cpp
// LC 23. Merge K Sorted Lists
struct ListNode { int val; ListNode* next; };

ListNode* mergeKLists(vector<ListNode*>& lists) {
    // Min heap: (value, list_index, node_pointer)
    auto cmp = [](ListNode* a, ListNode* b) { return a->val > b->val; };
    priority_queue<ListNode*, vector<ListNode*>, decltype(cmp)> minPQ(cmp);

    for (ListNode* node : lists)
        if (node) minPQ.push(node);

    ListNode dummy(0);
    ListNode* curr = &dummy;

    while (!minPQ.empty()) {
        ListNode* node = minPQ.top(); minPQ.pop();
        curr->next = node;
        curr = curr->next;
        if (node->next) minPQ.push(node->next);
    }
    return dummy.next;
}
```

```cpp
// LC 378. Kth Smallest Element in a Sorted Matrix
// Min heap: start with first element of each row
int kthSmallest(vector<vector<int>>& matrix, int k) {
    int n = matrix.size();
    // (value, row, col)
    priority_queue<tuple<int,int,int>, vector<tuple<int,int,int>>, greater<>> minPQ;
    for (int r = 0; r < n; r++)
        minPQ.push({matrix[r][0], r, 0});

    int ans = 0;
    for (int i = 0; i < k; i++) {
        auto [val, r, c] = minPQ.top(); minPQ.pop();
        ans = val;
        if (c + 1 < n)
            minPQ.push({matrix[r][c+1], r, c+1});
    }
    return ans;
}
```

## Pattern 1D: Two Heaps — Median of Data Stream

Maintain a max heap for the lower half and a min heap for the upper half.
Balance sizes so they differ by at most 1. Median is the top of one or
average of both tops.

```cpp
// LC 295. Find Median from Data Stream
class MedianFinder {
    priority_queue<int> lower;                          // max heap (lower half)
    priority_queue<int, vector<int>, greater<int>> upper; // min heap (upper half)

public:
    void addNum(int num) {
        lower.push(num);                   // always push to lower first
        upper.push(lower.top());           // balance: move max of lower to upper
        lower.pop();
        if (upper.size() > lower.size()) { // keep lower >= upper in size
            lower.push(upper.top());
            upper.pop();
        }
    }

    double findMedian() {
        if (lower.size() > upper.size())
            return lower.top();
        return (lower.top() + upper.top()) / 2.0;
    }
};
```

## Pattern 1E: Task Scheduling / Greedy with Heap

```cpp
// LC 621. Task Scheduler
// Always do the most frequent remaining task.
// If forced to idle, count idle time.
int leastInterval(vector<char>& tasks, int n) {
    vector<int> freq(26, 0);
    for (char c : tasks) freq[c - 'A']++;

    priority_queue<int> maxPQ(freq.begin(), freq.end()); // max heap by frequency

    int time = 0;
    while (!maxPQ.empty()) {
        vector<int> temp;
        int cycle = n + 1; // one full cycle of (n+1) slots
        while (cycle-- && !maxPQ.empty()) {
            temp.push_back(maxPQ.top() - 1);
            maxPQ.pop();
            time++;
        }
        for (int f : temp)
            if (f > 0) maxPQ.push(f);
        if (!maxPQ.empty())
            time += cycle + 1; // remaining idle slots in this cycle
    }
    return time;
}
```

```cpp
// LC 767. Reorganize String
// No two adjacent characters the same
// Greedy: always place the most frequent remaining character
string reorganizeString(string s) {
    vector<int> freq(26, 0);
    for (char c : s) freq[c - 'A']++;

    priority_queue<pair<int,int>> maxPQ; // (freq, char)
    for (int i = 0; i < 26; i++)
        if (freq[i]) maxPQ.push({freq[i], i});

    string ans = "";
    while (maxPQ.size() >= 2) {
        auto [f1, c1] = maxPQ.top(); maxPQ.pop();
        auto [f2, c2] = maxPQ.top(); maxPQ.pop();
        ans += (char)('A' + c1);
        ans += (char)('A' + c2);
        if (f1 - 1) maxPQ.push({f1 - 1, c1});
        if (f2 - 1) maxPQ.push({f2 - 1, c2});
    }
    if (!maxPQ.empty()) {
        if (maxPQ.top().first > 1) return "";
        ans += (char)('A' + maxPQ.top().second);
    }
    return ans;
}
```

# PART 2: INTERVALS

## Core Insight

Most interval problems reduce to one of four operations:
1. **Merge**: combine overlapping intervals into one
2. **Insert**: add a new interval into a sorted, non-overlapping set
3. **Count overlaps**: how many intervals overlap at a point or simultaneously
4. **Minimize / maximize**: remove fewest, schedule most, find gaps

Always sort by start time first unless the problem gives you another ordering hint.

---

## Overlap Condition

Two intervals [a, b] and [c, d] overlap if and only if:
```
a <= d  AND  c <= b
```
They do NOT overlap if `b < c` or `d < a`.

Merged interval when they do overlap:
```
[min(a, c), max(b, d)]
```

---

## Pattern 2A: Merge Intervals

Sort by start. Walk through: if current interval overlaps with the last
merged interval, extend it. Otherwise push a new one.

```cpp
// LC 56. Merge Intervals
vector<vector<int>> merge(vector<vector<int>>& intervals) {
    sort(intervals.begin(), intervals.end()); // sort by start
    vector<vector<int>> merged;

    for (auto& iv : intervals) {
        if (merged.empty() || merged.back()[1] < iv[0]) {
            merged.push_back(iv); // no overlap: add new
        } else {
            merged.back()[1] = max(merged.back()[1], iv[1]); // overlap: extend
        }
    }
    return merged;
}
```

---

## Pattern 2B: Insert Interval

Three phases: add all intervals that end before new interval starts, merge
all overlapping intervals with the new one, add all remaining.

```cpp
// LC 57. Insert Interval
vector<vector<int>> insert(vector<vector<int>>& intervals, vector<int>& newInterval) {
    vector<vector<int>> ans;
    int i = 0, n = intervals.size();

    // Phase 1: intervals that end before new interval starts (no overlap)
    while (i < n && intervals[i][1] < newInterval[0])
        ans.push_back(intervals[i++]);

    // Phase 2: merge all overlapping intervals into newInterval
    while (i < n && intervals[i][0] <= newInterval[1]) {
        newInterval[0] = min(newInterval[0], intervals[i][0]);
        newInterval[1] = max(newInterval[1], intervals[i][1]);
        i++;
    }
    ans.push_back(newInterval);

    // Phase 3: remaining intervals (start after new interval ends)
    while (i < n)
        ans.push_back(intervals[i++]);

    return ans;
}
```

## Pattern 2C: Non-Overlapping Intervals (Minimum Removals)

Greedy: sort by END time. Greedily keep intervals with the earliest end.
An interval that ends earlier leaves more room for future intervals.

```cpp
// LC 435. Non-overlapping Intervals
// Minimum number of intervals to remove so none overlap
int eraseOverlapIntervals(vector<vector<int>>& intervals) {
    sort(intervals.begin(), intervals.end(),
         [](auto& a, auto& b) { return a[1] < b[1]; }); // sort by END

    int removals = 0;
    int prev_end = INT_MIN;

    for (auto& iv : intervals) {
        if (iv[0] >= prev_end) {
            prev_end = iv[1]; // keep this interval
        } else {
            removals++; // overlap: remove current (it ends later)
        }
    }
    return removals;
}
```

**Why sort by end?** The interval that ends earliest is always at least as
good to keep as any other choice. Keeping it never makes future choices
worse.

## Pattern 2D: Meeting Rooms I & II

```cpp
// LC 252. Meeting Rooms I
// Can one person attend all meetings? -> no overlaps allowed
bool canAttendMeetings(vector<vector<int>>& intervals) {
    sort(intervals.begin(), intervals.end());
    for (int i = 1; i < intervals.size(); i++)
        if (intervals[i][0] < intervals[i-1][1])
            return false;
    return true;
}
```

```cpp
// LC 253. Meeting Rooms II
// Minimum number of conference rooms required
// = maximum number of meetings overlapping at any point in time
int minMeetingRooms(vector<vector<int>>& intervals) {
    sort(intervals.begin(), intervals.end()); // sort by start

    // Min heap stores END times of ongoing meetings
    priority_queue<int, vector<int>, greater<int>> minPQ;

    for (auto& iv : intervals) {
        if (!minPQ.empty() && minPQ.top() <= iv[0])
            minPQ.pop(); // reuse the room that freed up earliest
        minPQ.push(iv[1]); // assign/book a room ending at iv[1]
    }
    return minPQ.size(); // rooms in use = meetings still running
}
```

## Pattern 2E: Sweep Line (Count Overlaps at Each Point)

Convert each interval into +1 at start and -1 at end+1, then sweep.

```cpp
// Count maximum overlapping intervals at any point
int maxOverlap(vector<vector<int>>& intervals) {
    map<int, int> events;
    for (auto& iv : intervals) {
        events[iv[0]]++;   // +1 when interval starts
        events[iv[1]]--;   // -1 when interval ends
    }
    int curr = 0, ans = 0;
    for (auto& [time, delta] : events) {
        curr += delta;
        ans = max(ans, curr);
    }
    return ans;
}
```

```cpp
// LC 2406. Divide Intervals into Minimum Number of Groups
// Same as Meeting Rooms II: answer = max simultaneous overlaps
int minGroups(vector<vector<int>>& intervals) {
    map<int, int> events;
    for (auto& iv : intervals) {
        events[iv[0]]++;
        events[iv[1] + 1]--; // +1 because end is inclusive
    }
    int curr = 0, ans = 0;
    for (auto& [t, d] : events) {
        curr += d;
        ans = max(ans, curr);
    }
    return ans;
}
```

## Pattern 2F: Interval Scheduling Maximization

Maximum number of non-overlapping intervals you can attend.
Greedy: sort by end time, greedily pick earliest-ending intervals.

```cpp
// LC 646. Maximum Length of Pair Chain
// (Same pattern as interval scheduling)
int findLongestChain(vector<vector<int>>& pairs) {
    sort(pairs.begin(), pairs.end(),
         [](auto& a, auto& b) { return a[1] < b[1]; }); // sort by end

    int count = 0, prev_end = INT_MIN;
    for (auto& p : pairs) {
        if (p[0] > prev_end) { // strict: p[0] > prev_end (chain condition)
            count++;
            prev_end = p[1];
        }
    }
    return count;
}
```

## Pattern 2G: Minimum Interval Containing Query Points

For each query point, find the smallest interval that contains it.
Sort intervals by size, use a min heap, process queries in order.

```cpp
// LC 1851. Minimum Interval to Include Each Query
vector<int> minInterval(vector<vector<int>>& intervals, vector<int>& queries) {
    // Sort intervals by size (length)
    sort(intervals.begin(), intervals.end(),
         [](auto& a, auto& b) { return a[1]-a[0] < b[1]-b[0]; });

    int n = queries.size();
    vector<int> idx(n);
    iota(idx.begin(), idx.end(), 0);
    sort(idx.begin(), idx.end(), [&](int a, int b) { return queries[a] < queries[b]; });

    // Min heap: (size, start, end) — smallest interval at top
    priority_queue<tuple<int,int,int>, vector<tuple<int,int,int>>, greater<>> minPQ;
    int i = 0;
    // Sort intervals by start for efficient insertion
    sort(intervals.begin(), intervals.end());
    vector<int> ans(n, -1);

    for (int qi : idx) {
        int q = queries[qi];
        // Add all intervals that start <= q
        while (i < intervals.size() && intervals[i][0] <= q) {
            int len = intervals[i][1] - intervals[i][0] + 1;
            minPQ.push({len, intervals[i][0], intervals[i][1]});
            i++;
        }
        // Remove intervals that end < q (don't contain q)
        while (!minPQ.empty() && get<2>(minPQ.top()) < q)
            minPQ.pop();
        if (!minPQ.empty())
            ans[qi] = get<0>(minPQ.top());
    }
    return ans;
}
```

## Pattern 2H: Employee Free Time / Gap Finding

Find gaps between a merged set of intervals.

```cpp
// LC 759. Employee Free Time
// All employee schedules combined; find gaps in merged result
// Treat as merge intervals problem on all intervals together

vector<vector<int>> employeeFreeTime(vector<vector<vector<int>>>& schedule) {
    vector<vector<int>> all;
    for (auto& emp : schedule)
        for (auto& iv : emp)
            all.push_back(iv);

    sort(all.begin(), all.end());

    vector<vector<int>> merged;
    for (auto& iv : all) {
        if (merged.empty() || merged.back()[1] < iv[0])
            merged.push_back(iv);
        else
            merged.back()[1] = max(merged.back()[1], iv[1]);
    }

    vector<vector<int>> gaps;
    for (int i = 1; i < merged.size(); i++)
        gaps.push_back({merged[i-1][1], merged[i][0]});
    return gaps;
}
```

## Pattern 2I: Interval List Intersections

Two-pointer approach on two sorted interval lists.

```cpp
// LC 986. Interval List Intersections
vector<vector<int>> intervalIntersection(vector<vector<int>>& A, vector<vector<int>>& B) {
    int i = 0, j = 0;
    vector<vector<int>> ans;

    while (i < A.size() && j < B.size()) {
        int lo = max(A[i][0], B[j][0]);
        int hi = min(A[i][1], B[j][1]);
        if (lo <= hi)
            ans.push_back({lo, hi}); // valid intersection

        // Advance the pointer with the smaller end
        if (A[i][1] < B[j][1]) i++;
        else j++;
    }
    return ans;
}
```

## Intervals Key Problems

| Problem | Sort By | Algorithm | Key Insight |
|---|---|---|---|
| 56. Merge Intervals | Start | Linear scan | Extend last merged if overlap |
| 57. Insert Interval | Already sorted | Three phases | Skip, merge, append |
| 435. Non-overlapping | End | Greedy keep | Remove = total - max kept |
| 252. Meeting Rooms I | Start | Linear scan | Any overlap -> false |

| 759. Employee Free Time | Start | Merge + gaps | Gaps between merged intervals |
| 1851. Min Interval per Query | Start | Sort queries + min heap | Offline: sort queries, sweep intervals |

## Combined: Heap + Intervals

These problems require both concepts together.

```cpp
// LC 502. IPO
// Max k projects within capital constraint
// Two heaps: min heap by capital (available projects), max heap by profit
int findMaximizedCapital(int k, int w, vector<int>& profits, vector<int>& capital) {
    int n = profits.size();
    // Min heap by capital required
    priority_queue<pair<int,int>, vector<pair<int,int>>, greater<>> capPQ;
    for (int i = 0; i < n; i++)
        capPQ.push({capital[i], profits[i]});

    // Max heap by profit (projects we can afford)
    priority_queue<int> profPQ;

    for (int i = 0; i < k; i++) {
        // Unlock all projects we can currently afford
        while (!capPQ.empty() && capPQ.top().first <= w) {
            profPQ.push(capPQ.top().second);
            capPQ.pop();
        }
        if (profPQ.empty()) break; // can't do any more projects
        w += profPQ.top();
        profPQ.pop();
    }
    return w;
}
```

```cpp
// LC 1642. Furthest Building You Can Reach
// Use ladders for the biggest jumps, bricks for smaller ones
// Min heap of size k (ladder count) tracks which jumps used ladders
int furthestBuilding(vector<int>& heights, int bricks, int ladders) {
    priority_queue<int, vector<int>, greater<int>> minPQ; // tracks ladder-used jumps

    for (int i = 0; i < heights.size() - 1; i++) {
        int diff = heights[i+1] - heights[i];
        if (diff <= 0) continue;

        minPQ.push(diff); // tentatively use a ladder here

        if (minPQ.size() > ladders) {
            // Too many ladder uses; convert smallest ladder use to bricks
            bricks -= minPQ.top();
            minPQ.pop();
            if (bricks < 0) return i;
        }
    }
    return heights.size() - 1;
}
```

```cpp
// LC 632. Smallest Range Covering Elements from K Lists
// Min heap tracks current element from each list; also track global max
vector<int> smallestRange(vector<vector<int>>& nums) {
    // Min heap: (value, list_index, element_index)
    priority_queue<tuple<int,int,int>, vector<tuple<int,int,int>>, greater<>> minPQ;
    int curr_max = INT_MIN;

    for (int i = 0; i < nums.size(); i++) {
        minPQ.push({nums[i][0], i, 0});
        curr_max = max(curr_max, nums[i][0]);
    }

    vector<int> ans = {minPQ.top() != minPQ.top() ? 0 : get<0>(minPQ.top()),
                       curr_max}; // placeholder
    ans = {get<0>(minPQ.top()), curr_max};

    while (true) {
        auto [val, r, c] = minPQ.top(); minPQ.pop();
        if (c + 1 == nums[r].size()) break; // one list exhausted
        minPQ.push({nums[r][c+1], r, c+1});
        curr_max = max(curr_max, nums[r][c+1]);
        int curr_min = get<0>(minPQ.top());
        if (curr_max - curr_min < ans[1] - ans[0])
            ans = {curr_min, curr_max};
    }
    return ans;
}
```

# Pattern Recognition Quick-Reference

| Signal in Problem | Category | Algorithm |
|---|---|---|
| Kth largest in stream or array | Heap | Min heap of size k |
| Kth smallest in sorted matrix | Heap | Min heap, one per row |
| K closest / most frequent | Heap | Opposite-type heap of size k |
| Median of stream | Two Heaps | Max heap lower + min heap upper |
| Merge k sorted lists | Min Heap | Heap of size k, push next from same list |
