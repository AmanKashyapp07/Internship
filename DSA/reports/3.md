# Sliding Window, Two Pointers, Stack & Monotonic Stack
## Master Interview & OA Guide (C++)

---

## How to Use This Guide

These four topics are tightly related. Two pointers and sliding window are both linear-scan techniques. Stack and monotonic stack are both stack-based but solve different problem shapes. The decision tree below places you in the right category within seconds.

---

## Master Decision Tree

```
Does the problem involve a contiguous subarray or substring?
  YES ->
    Is the window size fixed?
      YES -> Fixed Sliding Window
      NO  ->
        Are you expanding/shrinking based on a condition?
          YES -> Variable Sliding Window
    Are you comparing two elements in the same array?
      YES -> Two Pointers (same array)

Does the problem involve TWO separate arrays or a sorted pair?
  YES -> Two Pointers (two arrays / two ends)

Does the problem ask about the NEXT or PREVIOUS greater/smaller element?
  YES -> Monotonic Stack

Does the problem involve matching brackets, undo operations, or nested structure?
  YES -> Stack

Does the problem ask for max/min in a sliding window?
  YES -> Monotonic Deque
```

# PART 1: TWO POINTERS

## When to Use
- Sorted array, find pair with target sum
- Remove duplicates in-place
- Reverse, palindrome check
- Merge two sorted arrays
- Fast-slow pointer for cycles or midpoints

## Signal Words
"sorted array", "pair with sum", "remove duplicates", "palindrome", "in-place", "two sorted"

---

## Pattern 1A: Opposite Ends (Left + Right)

Move left and right toward each other. Used when the array is sorted or when you want to shrink the search space from both ends.

```cpp
// Template: Two Sum in sorted array
// LC 167. Two Sum II
vector<int> twoSum(vector<int>& numbers, int target) {
    int left = 0, right = numbers.size() - 1;
    while (left < right) {
        int sum = numbers[left] + numbers[right];
        if (sum == target)
            return {left + 1, right + 1};
        else if (sum < target)
            left++;
        else
            right--;
    }
    return {};
}
```

```cpp
// LC 11. Container With Most Water
int maxArea(vector<int>& height) {
    int left = 0, right = height.size() - 1;
    int ans = 0;
    while (left < right) {
        ans = max(ans, min(height[left], height[right]) * (right - left));
        if (height[left] < height[right])
            left++;
        else
            right--;
    }
    return ans;
}
```

```cpp
// LC 15. 3Sum
// Sort first, then fix one element, two-pointer on the rest
vector<vector<int>> threeSum(vector<int>& nums) {
    sort(nums.begin(), nums.end());
    vector<vector<int>> ans;
    int n = nums.size();
    for (int i = 0; i < n - 2; i++) {
        if (i > 0 && nums[i] == nums[i-1]) continue; // skip duplicates
        int left = i + 1, right = n - 1;
        while (left < right) {
            int sum = nums[i] + nums[left] + nums[right];
            if (sum == 0) {
                ans.push_back({nums[i], nums[left], nums[right]});
                while (left < right && nums[left] == nums[left+1]) left++;
                while (left < right && nums[right] == nums[right-1]) right--;
                left++; right--;
            } else if (sum < 0) left++;
            else right--;
        }
    }
    return ans;
}
```

## Pattern 1B: Same Direction (Fast + Slow)

Both pointers start at the same end. Fast pointer scans ahead, slow pointer marks a position.

```cpp
// LC 26. Remove Duplicates from Sorted Array
int removeDuplicates(vector<int>& nums) {
    if (nums.empty()) return 0;
    int slow = 0;
    for (int fast = 1; fast < nums.size(); fast++) {
        if (nums[fast] != nums[slow]) {
            slow++;
            nums[slow] = nums[fast];
        }
    }
    return slow + 1;
}
```

```cpp
// LC 141. Linked List Cycle (Floyd's algorithm)
bool hasCycle(ListNode* head) {
    ListNode* slow = head;
    ListNode* fast = head;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) return true;
    }
    return false;
}
```

```cpp
// LC 142. Linked List Cycle II — find cycle entry point
ListNode* detectCycle(ListNode* head) {
    ListNode* slow = head;
    ListNode* fast = head;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) {
            // Reset slow to head; advance both at same speed
            slow = head;
            while (slow != fast) {
                slow = slow->next;
                fast = fast->next;
            }
            return slow;
        }
    }
    return nullptr;
}
```

## Pattern 1C: Two Arrays

One pointer per array. Common in merge operations.

```cpp
// LC 88. Merge Sorted Array (merge from the back)
void merge(vector<int>& nums1, int m, vector<int>& nums2, int n) {
    int i = m - 1, j = n - 1, k = m + n - 1;
    while (i >= 0 && j >= 0) {
        if (nums1[i] > nums2[j])
            nums1[k--] = nums1[i--];
        else
            nums1[k--] = nums2[j--];
    }
    while (j >= 0)
        nums1[k--] = nums2[j--];
}
```

# PART 2: SLIDING WINDOW

## When to Use
- Subarray or substring of some length
- "Longest", "shortest", "maximum", "minimum" over a contiguous range
- Constraint involves sum, count of distinct, frequency

## Signal Words
"subarray", "substring", "contiguous", "window of size k", "longest with", "minimum length"

---

## Pattern 2A: Fixed Size Window

Window size is given (k). Slide by adding the new right element and removing the leftmost.

```cpp
// Template: max sum subarray of size k
// LC 643. Maximum Average Subarray I
double findMaxAverage(vector<int>& nums, int k) {
    double window_sum = 0;
    for (int i = 0; i < k; i++)
        window_sum += nums[i];

    double ans = window_sum;
    for (int i = k; i < nums.size(); i++) {
        window_sum += nums[i] - nums[i - k]; // add new, remove old
        ans = max(ans, window_sum);
    }
    return ans / k;
}
```

```cpp
// LC 567. Permutation in String
// Fixed window of size s1.length; check if frequency maps match
bool checkInclusion(string s1, string s2) {
    if (s1.size() > s2.size()) return false;
    vector<int> need(26, 0), have(26, 0);
    int k = s1.size();
    for (char c : s1) need[c - 'a']++;
    for (int i = 0; i < k; i++) have[s2[i] - 'a']++;
    if (need == have) return true;
    for (int i = k; i < s2.size(); i++) {
        have[s2[i] - 'a']++;
        have[s2[i - k] - 'a']--;
        if (need == have) return true;
    }
    return false;
}
```

## Pattern 2B: Variable Size Window (Expand / Shrink)

Expand right pointer freely. Shrink left pointer when a constraint is violated.

```cpp
// Template: longest subarray satisfying some condition
int left = 0;
int ans = 0;
// state variables (sum, count, frequency map, etc.)

for (int right = 0; right < n; right++) {
    // expand: include nums[right] into window
    // update state

    while (/* constraint violated */) {
        // shrink: remove nums[left] from window
        // update state
        left++;
    }

    ans = max(ans, right - left + 1);
}
```

```cpp
// LC 3. Longest Substring Without Repeating Characters
int lengthOfLongestSubstring(string s) {
    unordered_map<char, int> freq;
    int left = 0, ans = 0;
    for (int right = 0; right < s.size(); right++) {
        freq[s[right]]++;
        while (freq[s[right]] > 1) {
            freq[s[left]]--;
            left++;
        }
        ans = max(ans, right - left + 1);
    }
    return ans;
}
```

```cpp
// LC 76. Minimum Window Substring
string minWindow(string s, string t) {
    unordered_map<char, int> need, have;
    for (char c : t) need[c]++;
    int formed = 0, required = need.size();
    int left = 0, min_len = INT_MAX, min_left = 0;

    for (int right = 0; right < s.size(); right++) {
        char c = s[right];
        have[c]++;
        if (need.count(c) && have[c] == need[c])
            formed++;

        while (formed == required) {
            if (right - left + 1 < min_len) {
                min_len = right - left + 1;
                min_left = left;
            }
            char lc = s[left];
            have[lc]--;
            if (need.count(lc) && have[lc] < need[lc])
                formed--;
            left++;
        }
    }
    return min_len == INT_MAX ? "" : s.substr(min_left, min_len);
}
```

```cpp
// LC 424. Longest Repeating Character Replacement
// Key insight: window is valid if (window_size - max_freq) <= k
int characterReplacement(string s, int k) {
    vector<int> freq(26, 0);
    int left = 0, max_freq = 0, ans = 0;
    for (int right = 0; right < s.size(); right++) {
        freq[s[right] - 'A']++;
        max_freq = max(max_freq, freq[s[right] - 'A']);
        while ((right - left + 1) - max_freq > k) {
            freq[s[left] - 'A']--;
            left++;
        }
        ans = max(ans, right - left + 1);
    }
    return ans;
}
```

```cpp
// LC 209. Minimum Size Subarray Sum
// Shortest subarray with sum >= target
int minSubArrayLen(int target, vector<int>& nums) {
    int left = 0, sum = 0, ans = INT_MAX;
    for (int right = 0; right < nums.size(); right++) {
        sum += nums[right];
        while (sum >= target) {
            ans = min(ans, right - left + 1);
            sum -= nums[left++];
        }
    }
    return ans == INT_MAX ? 0 : ans;
}
```

## Pattern 2C: At Most K Trick

"Exactly K" problems are often solved as `atMost(k) - atMost(k-1)`.

```cpp
// LC 992. Subarrays with K Different Integers
// Count subarrays with exactly k distinct = atMost(k) - atMost(k-1)
int atMost(vector<int>& nums, int k) {
    unordered_map<int, int> freq;
    int left = 0, ans = 0;
    for (int right = 0; right < nums.size(); right++) {
        freq[nums[right]]++;
        while (freq.size() > k) {
            freq[nums[left]]--;
            if (freq[nums[left]] == 0) freq.erase(nums[left]);
            left++;
        }
        ans += right - left + 1; // all subarrays ending at right
    }
    return ans;
}

int subarraysWithKDistinct(vector<int>& nums, int k) {
    return atMost(nums, k) - atMost(nums, k - 1);
}
```

# PART 3: STACK

## When to Use
- Matching/balancing: brackets, tags, pairs
- Undo operations, history tracking
- Nested structures (DFS iterative, expression evaluation)
- "Most recent" element that satisfies a condition

## Signal Words
"valid parentheses", "matching brackets", "evaluate expression", "undo", "nested", "decode"

---

## Pattern 3A: Matching / Balancing

```cpp
// LC 20. Valid Parentheses
bool isValid(string s) {
    stack<char> st;
    unordered_map<char, char> match = {{')', '('}, {']', '['}, {'}', '{'}};
    for (char c : s) {
        if (c == '(' || c == '[' || c == '{') {
            st.push(c);
        } else {
            if (st.empty() || st.top() != match[c])
                return false;
            st.pop();
        }
    }
    return st.empty();
}
```

```cpp
// LC 1047. Remove All Adjacent Duplicates in String
string removeDuplicates(string s) {
    string st; // use string as stack
    for (char c : s) {
        if (!st.empty() && st.back() == c)
            st.pop_back();
        else
            st.push_back(c);
    }
    return st;
}
```

## Pattern 3B: Expression Evaluation

```cpp
// LC 150. Evaluate Reverse Polish Notation
int evalRPN(vector<string>& tokens) {
    stack<long long> st;
    for (string& t : tokens) {
        if (t == "+" || t == "-" || t == "*" || t == "/") {
            long long b = st.top(); st.pop();
            long long a = st.top(); st.pop();
            if (t == "+") st.push(a + b);
            else if (t == "-") st.push(a - b);
            else if (t == "*") st.push(a * b);
            else st.push(a / b);
        } else {
            st.push(stoll(t));
        }
    }
    return st.top();
}
```

## Pattern 3C: Iterative DFS / Nested Structure

```cpp
// LC 394. Decode String
// "3[a2[c]]" -> "accaccacc"
string decodeString(string s) {
    stack<int> counts;
    stack<string> strs;
    string curr = "";
    int k = 0;
    for (char c : s) {
        if (isdigit(c)) {
            k = k * 10 + (c - '0');
        } else if (c == '[') {
            counts.push(k);
            strs.push(curr);
            curr = "";
            k = 0;
        } else if (c == ']') {
            int repeat = counts.top(); counts.pop();
            string prev = strs.top(); strs.pop();
            for (int i = 0; i < repeat; i++)
                prev += curr;
            curr = prev;
        } else {
            curr += c;
        }
    }
    return curr;
}
```

# PART 4: MONOTONIC STACK

## When to Use
Find the next/previous greater or smaller element for each position. Also used for largest rectangle, trapping rain water, and stock span problems.

## Signal Words
"next greater", "next smaller", "previous greater", "stock span", "largest rectangle", "trapping rain"

## Core Idea
Maintain a stack that is always sorted (increasing or decreasing). When the current element violates the order, pop elements off and compute answers for those popped elements.

---

## Pattern 4A: Next Greater Element (Decreasing Stack)

```cpp
// LC 496. Next Greater Element I
// For each element, find the next element to the right that is greater
// Stack stores candidates in decreasing order (top is smallest so far)

vector<int> nextGreaterElement(vector<int>& nums1, vector<int>& nums2) {
    unordered_map<int, int> next_greater;
    stack<int> st; // decreasing stack (top = smallest)

    for (int x : nums2) {
        while (!st.empty() && st.top() < x) {
            next_greater[st.top()] = x; // x is the next greater for st.top()
            st.pop();
        }
        st.push(x);
    }
    // remaining in stack have no next greater -> -1 (default)

    vector<int> ans;
    for (int x : nums1)
        ans.push_back(next_greater.count(x) ? next_greater[x] : -1);
    return ans;
}
```

```cpp
// LC 739. Daily Temperatures
// For each day, how many days until a warmer temperature?
// Stack stores INDICES, not values

vector<int> dailyTemperatures(vector<int>& temps) {
    int n = temps.size();
    vector<int> ans(n, 0);
    stack<int> st; // indices, decreasing by temperature

    for (int i = 0; i < n; i++) {
        while (!st.empty() && temps[st.top()] < temps[i]) {
            int idx = st.top(); st.pop();
            ans[idx] = i - idx; // days to wait
        }
        st.push(i);
    }
    return ans;
}
```

## Pattern 4B: Next Smaller Element (Increasing Stack)

```cpp
// Template: next smaller element to the right
vector<int> nextSmaller(vector<int>& nums) {
    int n = nums.size();
    vector<int> ans(n, -1);
    stack<int> st; // indices, increasing by value (top = largest)

    for (int i = 0; i < n; i++) {
        while (!st.empty() && nums[st.top()] > nums[i]) {
            ans[st.top()] = nums[i];
            st.pop();
        }
        st.push(i);
    }
    return ans;
}
```

## Pattern 4C: Largest Rectangle in Histogram

This is the canonical hard monotonic stack problem. Every bar's maximum rectangle width is bounded by the nearest shorter bar on each side.

```cpp
// LC 84. Largest Rectangle in Histogram
int largestRectangleArea(vector<int>& heights) {
    stack<int> st; // increasing stack of indices
    int ans = 0;
    int n = heights.size();

    for (int i = 0; i <= n; i++) {
        int curr = (i == n) ? 0 : heights[i]; // sentinel 0 at end to flush stack
        while (!st.empty() && heights[st.top()] > curr) {
            int h = heights[st.top()]; st.pop();
            int width = st.empty() ? i : i - st.top() - 1;
            ans = max(ans, h * width);
        }
        st.push(i);
    }
    return ans;
}
```

```cpp
// LC 85. Maximal Rectangle (matrix)
// Build histogram row by row, apply LC 84 on each row
int maximalRectangle(vector<vector<char>>& matrix) {
    if (matrix.empty()) return 0;
    int cols = matrix[0].size();
    vector<int> heights(cols, 0);
    int ans = 0;

    for (auto& row : matrix) {
        for (int j = 0; j < cols; j++)
            heights[j] = (row[j] == '0') ? 0 : heights[j] + 1;
        ans = max(ans, largestRectangleArea(heights));
    }
    return ans;
}
```

## Pattern 4D: Trapping Rain Water

```cpp
// LC 42. Trapping Rain Water
// Two-pointer approach (O(1) space)
int trap(vector<int>& height) {
    int left = 0, right = height.size() - 1;
    int left_max = 0, right_max = 0;
    int ans = 0;

    while (left < right) {
        if (height[left] < height[right]) {
            if (height[left] >= left_max)
                left_max = height[left];
            else
                ans += left_max - height[left];
            left++;
        } else {
            if (height[right] >= right_max)
                right_max = height[right];
            else
                ans += right_max - height[right];
            right--;
        }
    }
    return ans;
}
```

## Pattern 4E: Monotonic Deque (Sliding Window Maximum)

When you need the maximum (or minimum) in a sliding window of fixed size k.

```cpp
// LC 239. Sliding Window Maximum
vector<int> maxSlidingWindow(vector<int>& nums, int k) {
    deque<int> dq; // stores indices; front is always the max
    vector<int> ans;

    for (int i = 0; i < nums.size(); i++) {
        // Remove indices that are out of the window
        if (!dq.empty() && dq.front() < i - k + 1)
            dq.pop_front();

        // Remove indices whose values are smaller than current (useless)
        while (!dq.empty() && nums[dq.back()] < nums[i])
            dq.pop_back();

        dq.push_back(i);

        if (i >= k - 1)
            ans.push_back(nums[dq.front()]);
    }
    return ans;
}
```

## Pattern 4F: Stock Span / Previous Greater

```cpp
// LC 901. Online Stock Span
// For each day, how many consecutive days (including today) had price <= today?
class StockSpanner {
    stack<pair<int,int>> st; // (price, span)
public:
    int next(int price) {
        int span = 1;
        while (!st.empty() && st.top().first <= price) {
            span += st.top().second;
            st.pop();
        }
        st.push({price, span});
        return span;
    }
};
```

# Choosing Stack Direction: Cheat Sheet

| Goal | Stack Order | Pop When |
|---|---|---|
| Next Greater to Right | Decreasing | current > top |
| Next Smaller to Right | Increasing | current < top |
| Previous Greater to Left | Decreasing | Process before pushing |
| Previous Smaller to Left | Increasing | Process before pushing |
| Largest Rectangle | Increasing | current < top |
| Sliding Window Max | Decreasing Deque | current > back; front out of window |
| Smallest number (remove digits) | Increasing | current < top |
