## PATTERN IDENTIFICATION
| Question says... | Think... |
| :--- | :--- |
| Visit every node | DFS / BFS |
| Ancestor query | Binary Lifting |
| Lowest common ancestor | LCA |
| K-th ancestor | Binary Lifting |
| Maximum path | Tree DP |
| Choose nodes optimally | Tree DP |
| Diameter | Double DFS/BFS |
| Distance to every node | Rerooting DP |
| Subtree information | Euler Tour + DP |
| Subtree updates | Euler Tour + Segment Tree |
| Path queries | HLD / Binary Lifting |
| BST property | BST Traversal |
| Build tree | Traversal Reconstruction |
| Serialize tree | DFS |
