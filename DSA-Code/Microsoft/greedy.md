**Interview Takeaway**

For OAs, the most important greedy patterns are:

**Sorting + choose optimal → Intervals → Scheduling → Two pointers → Heap greedy → String/monotonic stack greedy.**

Mastering these patterns is much more valuable than memorizing 100 individual solutions.
