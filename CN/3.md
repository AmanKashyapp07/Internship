# Computer Networks — 40 High-Yield Interview Q&A (Microsoft Prep)

## Category 1: Architecture, Layers & Devices

### 1. What is the difference between the OSI and TCP/IP models?
The OSI model is a 7-layer theoretical reference framework, whereas TCP/IP is a 4-layer practical model implemented on the Internet. TCP/IP collapses OSI's Physical and Data Link layers into the Network Access/Link layer, and collapses Session, Presentation, and Application layers into a single Application layer.

### 2. What are the Protocol Data Units (PDUs) at each layer?
- Layer 1 (Physical): **Bits**
- Layer 2 (Data Link): **Frames**
- Layer 3 (Network): **Packets**
- Layer 4 (Transport): **Segments** (TCP) or **Datagrams** (UDP)
- Layer 7 (Application): **Data / Messages**

### 3. What is the difference between a Hub, a Switch, and a Router?
A **Hub** (Layer 1) is an unmanaged device that broadcasts incoming bits to all connected ports. A **Switch** (Layer 2) uses MAC addresses to forward frames specifically to the destination device's port. A **Router** (Layer 3) inspects IP addresses to route packets across different networks and subnets.

### 4. What is a Collision Domain vs. a Broadcast Domain?
A **collision domain** is a network segment where data packets can collide with one another (a switch creates a separate collision domain on each port). A **broadcast domain** is a network area where all devices receive any broadcast frame sent (switches forward broadcasts; only routers break broadcast domains).

### 5. What is the difference between Half-Duplex and Full-Duplex?
In **half-duplex**, data can travel in both directions, but only one direction at a time (like a walkie-talkie). In **full-duplex**, data travels in both directions simultaneously (like a telephone call or modern Ethernet/TCP).

## Category 2: TCP, UDP & Transport Layer

### 6. What is the primary difference between TCP and UDP?
TCP is connection-oriented, reliable (guarantees delivery via ACKs and retransmissions), and preserves message order using sequence numbers. UDP is connectionless, lightweight, and does not guarantee delivery, order, or congestion control, prioritizing speed and low latency.

### 7. Explain the TCP 3-way handshake.
The client sends a `SYN` packet with an initial sequence number ($x$). The server replies with a `SYN-ACK` packet acknowledging $x+1$ and providing its own sequence number ($y$). The client then sends an `ACK` packet acknowledging $y+1$. Once received, the connection is established.

### 8. Why does TCP use a 3-way handshake instead of a 2-way handshake?
A 2-way handshake only confirms the server heard the client, but leaves the client unable to acknowledge the server's sequence number. Furthermore, delayed or duplicate `SYN` packets wandering in the network could fool the server into opening unwanted phantom connections.

### 9. Explain the TCP 4-way connection termination.
Because TCP is full-duplex, each direction closes independently:
1. Client sends `FIN`
2. Server responds with `ACK` (half-close: client can still receive)
3. Server finishes sending remaining data and sends its own `FIN`
4. Client responds with `ACK`

### 10. What is the purpose of the `TIME_WAIT` state in TCP?
The initiating endpoint waits in `TIME_WAIT` for $2 \times \text{MSL}$ (Maximum Segment Lifetime) before closing the port. This ensures the final `ACK` reached the other side (allowing retransmission if lost) and prevents old, lingering packets from corrupting a new connection reusing the same port.

### 11. What is the difference between Flow Control and Congestion Control in TCP?
**Flow control** prevents a fast sender from overwhelming a slow *receiver* using a sliding window advertised by the receiver. **Congestion control** prevents a sender from overwhelming the *intermediate network* routers using congestion window mechanisms (Slow Start, Congestion Avoidance).

### 12. What is a Port and what is a Socket?
A **Port** is a 16-bit number (0–65535) that identifies a specific application/service process on a host. A **Socket** is an operational communication endpoint formed by the tuple: `(Source IP, Source Port, Destination IP, Destination Port, Protocol)`.

### 13. What is a SYN Flood attack?
A Denial of Service (DoS) attack where an attacker sends a flood of TCP `SYN` packets with forged source IPs, ignoring the server's `SYN-ACK`. The server wastes memory allocating half-open connections until legitimate traffic is rejected. It is mitigated using **SYN Cookies**.

## Category 3: IP Addressing, ARP, DHCP & Routing

### 14. What is the difference between a MAC address and an IP address?
A MAC address is a 48-bit physical hardware address permanently assigned to a device's Network Interface Card (used for local hop-by-hop delivery within a LAN). An IP address is a 32-bit (IPv4) or 128-bit (IPv6) logical address configured via software (used for global end-to-end routing across the Internet).

### 15. What is ARP (Address Resolution Protocol) and how does it work?
ARP translates a known Layer 3 IP address to a physical Layer 2 MAC address on the local network. A device broadcasts an ARP Request (`Who has IP X?`) to all hosts, and the owner replies with a unicast ARP Reply containing its MAC address, which is then cached locally.

### 16. What is DHCP and what is the DORA process?
DHCP automatically assigns dynamic IP configurations to devices joining a network via 4 UDP messages:
- **D**iscover: Client broadcasts looking for a DHCP server.
- **O**ffer: Server offers an available IP address.
- **R**equest: Client requests to lease the offered IP.
- **A**cknowledge: Server confirms the lease and provides subnet mask, default gateway, and DNS servers.

### 17. What is NAT (Network Address Translation) and why is it needed?
NAT allows an entire private local network (using non-routable RFC 1918 IPs like `192.168.x.x`) to share a single public IP address when accessing the Internet. It was invented to mitigate IPv4 address exhaustion and adds a layer of security by hiding internal network topologies.

### 18. What is a Subnet and Subnet Mask?
A subnet is a logical partition of an IP network. A subnet mask (e.g., `255.255.255.0` or `/24`) is a bitmask that separates the IP address into the **Network ID** (routing prefix) and the **Host ID** (individual device identifier).

### 19. What are the reserved Private IP ranges?
Under RFC 1918:
- **Class A**: `10.0.0.0 – 10.255.255.255`
- **Class B**: `172.16.0.0 – 172.31.255.255`
- **Class C**: `192.168.0.0 – 192.168.255.255`

### 20. What is ICMP and how does `ping` use it?
ICMP (Internet Control Message Protocol) is a Layer 3 network diagnostic and error-reporting protocol. The `ping` command sends an `ICMP Echo Request` (Type 8) to test destination reachability and measures the round-trip time for the `ICMP Echo Reply` (Type 0). It does not use port numbers.

### 21. What is TTL (Time to Live) in an IP packet?
TTL is an 8-bit field in the IPv4 header (Hop Limit in IPv6) that decrements by 1 at every router hop. When it hits 0, the packet is discarded and an ICMP Time Exceeded message is sent back to the sender, preventing infinite routing loops.

## Category 4: Web, HTTP, HTTPS & DNS

### 22. What is the difference between HTTP and HTTPS?
HTTP transmits plaintext data over TCP port 80 and is vulnerable to eavesdropping and tampering. HTTPS runs HTTP over a TLS/SSL encrypted connection on TCP port 443, providing encryption, data integrity, and server authentication via certificates.

### 23. What happens in an SSL/TLS handshake?
The client and server exchange random numbers and supported cipher suites (ClientHello / ServerHello). The server presents its digital certificate, which the client validates against trusted Certificate Authorities (CAs). Both parties then derive a shared symmetric session key used for fast, bulk data encryption.

### 24. What is the difference between Symmetric and Asymmetric encryption?
Symmetric encryption uses a single shared key for both encryption and decryption (very fast, used for data transfer in HTTPS). Asymmetric encryption uses a mathematically linked public/private key pair (slower, used during the TLS handshake to safely share the symmetric key).

### 25. What does it mean for an HTTP method to be Safe vs. Idempotent?
- **Safe**: Calling the method does not modify any server state (e.g., `GET`, `HEAD`, `OPTIONS`).
- **Idempotent**: Making multiple identical requests results in the same server state as making a single request (e.g., `GET`, `PUT`, `DELETE`). `POST` is neither safe nor idempotent.

### 26. What is the difference between `PUT` and `PATCH`?
`PUT` replaces the **entire** target resource with the uploaded payload (idempotent). `PATCH` applies **partial** modifications/deltas to an existing resource (not necessarily idempotent).

### 27. What is the difference between HTTP/1.1, HTTP/2, and HTTP/3?
- **HTTP/1.1**: Persistent TCP connections with Keep-Alive, but suffers from application-layer Head-of-Line (HoL) blocking.
- **HTTP/2**: Introduces binary framing, header compression (HPACK), and multiplexing of multiple streams over a single TCP connection.
- **HTTP/3**: Replaces TCP with **QUIC (over UDP)**, eliminating TCP-level HoL blocking and accelerating handshake latency.

### 28. What is the difference between a 301 and a 302 redirect?
A `301 Moved Permanently` tells browsers and search engines that the URL has permanently changed, prompting browsers to cache the redirect and transfer SEO link authority. A `302 Found` is temporary; browsers do not permanently cache it and continue requesting the original URL.

### 29. What is the difference between a 401 and a 403 status code?
A `401 Unauthorized` means authentication is missing or invalid (identity unverified). A `403 Forbidden` means the server knows the client's identity, but the client lacks permission/authorization to access the requested resource.

### 30. What is the difference between a 502 and a 504 status code?
Both occur at an intermediate reverse proxy/gateway:
- `502 Bad Gateway`: The proxy received an invalid, corrupted, or connection-refused response from the upstream server.
- `504 Gateway Timeout`: The proxy timed out waiting for the upstream server to reply.

### 31. What is DNS and how does it work?
DNS (Domain Name System) translates human-readable domain names into IP addresses. A query walks hierarchically: Browser/OS Cache ➔ Recursive Resolver ➔ Root Nameserver (`.`) ➔ TLD Nameserver (`.com`) ➔ Authoritative Nameserver (`example.com`), which returns the IP address.

### 32. What is the difference between an `A` record and a `CNAME` record?
An **A record** maps a domain directly to an IPv4 address (`example.com ➔ 93.184.216.34`). A **CNAME record** (Canonical Name) maps an alias domain to another domain name (`www.example.com ➔ example.com`), requiring an extra DNS resolution step.

### 33. Why does DNS use UDP port 53 instead of TCP?
DNS queries are small (< 512 bytes) and require speed. UDP avoids the 3-way handshake round-trip latency. DNS only falls back to TCP when the response exceeds 512 bytes (truncated flag set), for DNSSEC, or for zone transfers between servers.

## Category 5: Web Architecture, Proxies, Caching & Security

### 34. What is the difference between a Forward Proxy and a Reverse Proxy?
A **forward proxy** sits in front of clients to hide client IPs, bypass geoblocks, or enforce corporate firewalls. A **reverse proxy** sits in front of web servers to distribute traffic (load balancing), terminate SSL/TLS, and cache static responses.

### 35. What is the difference between L4 and L7 Load Balancing?
An **L4 Load Balancer** makes forwarding decisions at the Transport Layer using only IP addresses and TCP/UDP ports (very fast, content-agnostic). An **L7 Load Balancer** inspects Application Layer data (HTTP headers, URL paths, cookies) to route requests intelligently (smarter, supports path-based routing, higher CPU cost).

### 36. What is a CDN (Content Delivery Network)?
A geographically distributed network of proxy servers (Edge servers) that cache static web content (images, CSS, JS, videos) close to end users, reducing latency, cutting origin server load, and mitigating DDoS spikes.

### 37. How do Cookies differ from LocalStorage and Sessions?
- **Cookies**: Small strings (≤ 4KB) sent automatically with every HTTP request in the `Cookie` header; can be secured with `HttpOnly` and `SameSite` flags.
- **LocalStorage**: Client-side storage (5–10MB) that persists indefinitely in the browser; never sent automatically in HTTP headers, accessible only via JavaScript.
- **Session**: Server-side storage holding user state; mapped to the user via a temporary `session_id` stored inside a cookie.

### 38. What is CORS (Cross-Origin Resource Sharing)?
CORS is a browser security mechanism enforcing the Same-Origin Policy. It prevents malicious websites on one origin (`site-a.com`) from reading sensitive API data from another origin (`site-b.com`) unless `site-b.com` explicitly grants permission via `Access-Control-Allow-Origin` response headers.

### 39. What is a WebSocket and when should it be used over HTTP?
WebSockets provide a persistent, bi-directional, full-duplex TCP connection established via an HTTP Upgrade handshake. They should be used for real-time applications requiring low-latency communication (e.g., chat apps, live collaborative editors, multiplayer gaming, financial tickers).

### 40. What is an ETag and how does conditional caching work?
An `ETag` (Entity Tag) is an HTTP response header containing a content hash of a resource. On subsequent visits, the client sends `If-None-Match: <hash>`. If the file hasn't changed, the server responds with `304 Not Modified` and an empty body, saving significant bandwidth.
