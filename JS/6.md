# Lecture 06: DOM Architecture, Event Flow, Delegation & Web APIs

## 1. DOM Rendering Lifecycle & Performance

### 1.1 Critical Rendering Path
1. **DOM Tree Creation**: HTML parsed into DOM nodes.
2. **CSSOM Tree Creation**: CSS parsed into CSS Object Model.
3. **Render Tree Construction**: Combines DOM and CSSOM (excludes `display: none` elements).
4. **Layout (Reflow)**: Calculates exact geometry, size, and position of each render tree node.
5. **Paint (Repaint)**: Fills pixels on screen (colors, borders, text, shadows).
6. **Compositing**: Draws layers onto screen GPU buffers.

```
HTML -> DOM  \
              +--> Render Tree -> Layout (Reflow) -> Paint -> Composite
CSS  -> CSSOM /
```

### 1.2 Reflow vs Repaint Bottlenecks
- **Reflow**: High performance cost! Triggered by changes to geometry (e.g. `width`, `height`, `margin`, `fontSize`, `offsetWidth`, `getBoundingClientRect()`).
- **Repaint**: Moderate cost. Triggered by visual changes that do not alter layout (e.g. `color`, `background-color`, `visibility`).

#### How to Prevent Layout Thrashing:
```javascript
// BAD: Layout Thrashing (Forcing Reflow inside a loop)
const boxes = document.querySelectorAll(".box");
for (let i = 0; i < boxes.length; i++) {
  // Reading offsetWidth forces browser to recalculate layout repeatedly!
  boxes[i].style.width = boxes[i].offsetWidth + 10 + "px";
}

// GOOD: Batch reads, then batch writes
const widths = Array.from(boxes).map(box => box.offsetWidth); // Batch Read
boxes.forEach((box, i) => {
  box.style.width = widths[i] + 10 + "px"; // Batch Write
});

// BEST: Use DocumentFragment for bulk insertions
const fragment = document.createDocumentFragment();
for (let i = 0; i < 100; i++) {
  const li = document.createElement("li");
  li.textContent = `Item ${i}`;
  fragment.appendChild(li); // No DOM reflow during loop!
}
document.querySelector("#list").appendChild(fragment); // Single reflow!
```

## 2. Event Propagation & Event Delegation

### 2.1 The 3 Phases of Event Propagation
```
           Window / Document
                 |  ^
  Phase 1:       |  |   Phase 3:
  Capturing      v  |   Bubbling
               [Parent]
                 |  ^
                 v  |
               [Target]  <-- Phase 2: Target Phase
```

```javascript
element.addEventListener("click", handler, useCapture);
// useCapture = false (default -> Bubbling phase)
// useCapture = true  (Fires during Capturing phase)
```

### 2.2 Propagation Control Methods
- `e.preventDefault()`: Cancels default browser behavior (e.g. form submit page reload, link navigation) without stopping event propagation.
- `e.stopPropagation()`: Stops the event from bubbling up or capturing down any further.
- `e.stopImmediatePropagation()`: Stops bubbling AND prevents other listeners on the **same element** from executing.

### 2.3 Event Delegation Pattern
Instead of attaching event listeners to hundreds of child elements, attach **one single listener to a common parent element**.

```html
<ul id="todo-list">
  <li data-id="1" class="item">Task 1 <button class="delete-btn">Delete</button></li>
  <li data-id="2" class="item">Task 2 <button class="delete-btn">Delete</button></li>
</ul>
```

```javascript
const todoList = document.querySelector("#todo-list");

// Single listener handles dynamic items added later!
todoList.addEventListener("click", (e) => {
  // Check if click was inside a delete button
  const deleteBtn = e.target.closest(".delete-btn");
  if (!deleteBtn) return;

  const listItem = deleteBtn.closest(".item");
  const taskId = listItem.dataset.id;
  
  console.log(`Deleting task ID: ${taskId}`);
  listItem.remove();
});
```

## 3. Essential Web APIs for Modern Applications

### 3.1 Fetch API with `AbortController` (Canceling Requests)
Prevents race conditions in search autocomplete components when rapid inputs trigger multiple network requests.

```javascript
class SearchService {
  constructor() {
    this.controller = null;
  }

  async search(query) {
    // Abort previous pending request if user types again
    if (this.controller) {
      this.controller.abort();
    }

    this.controller = new AbortController();

    try {
      const response = await fetch(`/api/search?q=${query}`, {
        signal: this.controller.signal
      });
      const data = await response.json();
      return data;
    } catch (err) {
      if (err.name === "AbortError") {
        console.log("Fetch aborted for stale query:", query);
      } else {
        console.error("Network error:", err);
      }
    }
  }
}
```

### 3.2 `IntersectionObserver` (Lazy Loading & Infinite Scroll)
Asynchronously observes changes in the intersection of a target element with an ancestor element or viewport.

```javascript
// Infinite Scrolling / Image Lazy Loading
const observer = new IntersectionObserver((entries, obs) => {
  entries.forEach((entry) => {
    if (entry.isIntersecting) {
      const img = entry.target;
      img.src = img.dataset.src; // Replace placeholder with actual image URL
      img.classList.remove("lazy");
      obs.unobserve(img); // Stop watching once loaded!
    }
  });
}, {
  root: null, // Viewport
  rootMargin: "200px 0px", // Preload 200px before scrolling into view
  threshold: 0.1
});

document.querySelectorAll("img.lazy").forEach(img => observer.observe(img));
```
