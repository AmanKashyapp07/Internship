# Lecture 05: Modern ES6+ Features, Iterators, Generators & Specialized Data Structures

## 1. Modern ES6+ Syntactic Power Features

### 1.1 Advanced Destructuring & Rest/Spread
Destructuring extracts data from arrays or objects into distinct variables with support for default values, variable renaming, and deep nesting.

```javascript
const userResponse = {
  id: 101,
  profile: {
    name: "Alex",
    socials: { twitter: "@alex_dev" }
  },
  roles: ["admin", "editor"]
};

// Renaming + Default values + Nested destructuring
const {
  profile: {
    name: username,
    socials: { twitter = "N/A" }
  },
  roles: [primaryRole, ...otherRoles]
} = userResponse;

console.log(username, twitter, primaryRole, otherRoles);
// Output: Alex @alex_dev admin ["editor"]
```

### 1.2 Modern Logical Operators (`??`, `?.`, `||=`, `&&=`, `??=`)
- **Nullish Coalescing (`??`)**: Evaluates fallback **only if** left side is `null` or `undefined` (unlike `||` which triggers on `0`, `""`, `false`, `NaN`).
- **Optional Chaining (`?.`)**: Short-circuits with `undefined` if reference is `nullish` before accessing property/method.
- **Logical Assignment**:
  - `a ||= b` (Assign if falsy)
  - `a &&= b` (Assign if truthy)
  - `a ??= b` (Assign if nullish)

```javascript
const config = {
  timeout: 0,
  title: ""
};

// || vs ??
console.log(config.timeout || 5000); // 5000 (0 is falsy - unwanted bug!)
console.log(config.timeout ?? 5000); // 0 (Correct!)

// Optional Chaining with methods
const api = { getData: () => "data" };
console.log(api.fetchData?.()); // undefined (No runtime TypeError thrown!)

// Logical Assignment
let settings = { retryCount: 0 };
settings.retryCount ??= 3; // Remains 0 (0 is not nullish)
settings.host ??= "localhost"; // Becomes "localhost"
```

## 2. Iterators & Generator Functions

### 2.1 The Iterable Protocol & `Symbol.iterator`
An object is an **Iterable** if it implements a method at key `[Symbol.iterator]` that returns an **Iterator** object with a `.next()` method returning `{ value, done }`.

```javascript
// Making a custom object iterable with for...of loop
const range = {
  from: 1,
  to: 3,
  [Symbol.iterator]() {
    let current = this.from;
    const last = this.to;
    return {
      next() {
        if (current <= last) {
          return { value: current++, done: false };
        } else {
          return { value: undefined, done: true };
        }
      }
    };
  }
};

for (const num of range) {
  console.log(num); // 1, 2, 3
}
```

### 2.2 Generator Functions (`function*` and `yield`)
Generators can **pause** execution using `yield` and **resume** later. They yield values one by one on `.next()`.

```javascript
function* idGenerator() {
  let id = 1;
  while (true) {
    const increment = yield id; // Receives value passed in next(val)
    id += increment || 1;
  }
}

const gen = idGenerator();
console.log(gen.next().value);    // 1 (Pauses at yield)
console.log(gen.next(5).value);   // 6 (Passes 5 into yield)
console.log(gen.next(10).value);  // 16
```

## 3. Specialized Data Structures: Map, Set, WeakMap & WeakSet

### 3.1 `Map` vs `Object`
| Feature | `Object` | `Map` |
| :--- | :--- | :--- |
| **Key Types** | Strings, Symbols only | **Any type** (Objects, Functions, Primitives) |
| **Key Ordering** | Complex string integer order | Preserves exact **insertion order** |
| **Performance** | Basic lookups | Optimized for **frequent additions & removals** |
| **Size** | Manual `Object.keys().length` | Direct `.size` property |

```javascript
const map = new Map();
const objKey = { id: 1 };

map.set(objKey, "User metadata");
console.log(map.get(objKey)); // "User metadata"
```

### 3.2 `WeakMap` & `WeakSet` (Garbage Collection Powerhouse)
- **`WeakMap`**: Keys **must be objects** (or non-registered symbols). Holds **weak references** to keys.
- If no other reference to key object exists, it gets **garbage collected** automatically, preventing memory leaks!
- Useful for storing private metadata or DOM element data without blocking GC.

```javascript
let element = document.createElement("div");

// WeakMap metadata store
const elementMetadata = new WeakMap();
elementMetadata.set(element, { clicks: 0 });

// If element is removed from DOM and dereferenced:
element = null; 
// Memory used by element and its metadata in WeakMap is automatically reclaimed!
```

## 4. Symbols & Well-Known Symbols

Symbols create **guaranteed unique identifiers** that never collide with other object keys.

```javascript
const ID_KEY = Symbol("id");
const user = {
  name: "Sarah",
  [ID_KEY]: 12345
};

console.log(user[ID_KEY]); // 12345
console.log(Object.keys(user)); // ["name"] (Symbol keys are hidden from normal iteration!)
console.log(Object.getOwnPropertySymbols(user)); // [ Symbol(id) ]

// Well-Known Symbols: Symbol.toPrimitive
const smartObj = {
  value: 42,
  [Symbol.toPrimitive](hint) {
    if (hint === "number") return this.value;
    if (hint === "string") return `Value is ${this.value}`;
    return this.value;
  }
};

console.log(+smartObj);        // 42 (Number conversion)
console.log(`${smartObj}`);    // "Value is 42" (String conversion)
```
