# Lecture 04: Functional Programming, High-Order Functions & Polyfills

## 1. Functional Programming Core Concepts

Functional Programming (FP) is a declarative programming paradigm centered around immutable data and pure functions.

### 1.1 Pure vs Impure Functions
A **Pure Function** satisfies two conditions:
1. Given the same inputs, it **always returns the exact same output**.
2. It causes **no side effects** (does not mutate global state, modify external parameters, or perform I/O).

```javascript
// Impure Function (relies on & mutates external state)
let taxRate = 0.05;
function calculateTotalImpure(amount) {
  return amount + (amount * taxRate); // Relies on external variable
}

// Pure Function (Self-contained, deterministic)
function calculateTotalPure(amount, rate) {
  return amount + (amount * rate);
}
```

### 1.2 High-Order Functions (HOFs)
A **High-Order Function** is a function that either:
- Accepts one or more functions as arguments (callback functions).
- Returns a function as its result.

## 2. Array High-Order Functions & Practical Patterns

### 2.1 Standard HOFs Overview
- `map(cb)`: Transforms each element into a new array of identical length.
- `filter(cb)`: Returns a new array containing elements that pass the predicate test.
- `reduce(cb, initialValue)`: Accumulates elements into a single value (object, number, array, etc.).
- `flatMap(cb)`: Maps each element then flattens result by 1 level.

### 2.2 Advanced `reduce` Power Patterns

```javascript
const transactions = [
  { type: "income", amount: 100, category: "salary" },
  { type: "expense", amount: 50, category: "food" },
  { type: "income", amount: 200, category: "freelance" },
  { type: "expense", amount: 30, category: "food" }
];

// Grouping by category & summing amounts
const summary = transactions.reduce((acc, curr) => {
  const { category, amount, type } = curr;
  if (!acc[category]) acc[category] = 0;
  
  acc[category] += type === "income" ? amount : -amount;
  return acc;
}, {});

console.log(summary);
// Output: { salary: 100, food: -80, freelance: 200 }
```

## 3. Top Interview Polyfills (Handwritten)

### 3.1 `Array.prototype.myMap`
```javascript
Array.prototype.myMap = function (callback) {
  if (typeof callback !== "function") {
    throw new TypeError(`${callback} is not a function`);
  }

  const result = [];
  // 'this' refers to the array calling myMap
  for (let i = 0; i < this.length; i++) {
    // Handle sparse arrays (ignore unassigned indices)
    if (i in this) {
      result.push(callback(this[i], i, this));
    }
  }
  return result;
};

// Test
console.log([1, 2, 3].myMap(x => x * 2)); // [2, 4, 6]
```

### 3.2 `Array.prototype.myFilter`
```javascript
Array.prototype.myFilter = function (callback) {
  if (typeof callback !== "function") {
    throw new TypeError(`${callback} is not a function`);
  }

  const result = [];
  for (let i = 0; i < this.length; i++) {
    if (i in this && callback(this[i], i, this)) {
      result.push(this[i]);
    }
  }
  return result;
};

// Test
console.log([1, 2, 3, 4].myFilter(x => x % 2 === 0)); // [2, 4]
```

### 3.3 `Array.prototype.myReduce`
```javascript
Array.prototype.myReduce = function (callback, initialValue) {
  if (typeof callback !== "function") {
    throw new TypeError(`${callback} is not a function`);
  }

  let accumulator = initialValue;
  let startIndex = 0;

  // If no initialValue provided, use first element as accumulator
  if (arguments.length < 2) {
    if (this.length === 0) {
      throw new TypeError("Reduce of empty array with no initial value");
    }
    accumulator = this[0];
    startIndex = 1;
  }

  for (let i = startIndex; i < this.length; i++) {
    if (i in this) {
      accumulator = callback(accumulator, this[i], i, this);
    }
  }
  return accumulator;
};

// Test
console.log([1, 2, 3, 4].myReduce((acc, val) => acc + val, 0)); // 10
```

### 3.4 `Promise.myAll` Polyfill
```javascript
Promise.myAll = function (promises) {
  return new Promise((resolve, reject) => {
    if (!Array.isArray(promises)) {
      return reject(new TypeError("Argument must be an Array"));
    }

    const results = [];
    let completedCount = 0;

    if (promises.length === 0) {
      return resolve([]);
    }

    promises.forEach((item, index) => {
      // Wrap non-promise values with Promise.resolve
      Promise.resolve(item)
        .then((val) => {
          results[index] = val; // Maintain original array order!
          completedCount++;

          if (completedCount === promises.length) {
            resolve(results);
          }
        })
        .catch((err) => reject(err)); // Fail fast on first error
    });
  });
};

// Test
const p1 = Promise.resolve(10);
const p2 = new Promise((res) => setTimeout(() => res(20), 100));
Promise.myAll([p1, p2, 30]).then(console.log); // [10, 20, 30]
```

## 4. Production Performance Utilities: Debounce & Throttle

### 4.1 Visualizing the Difference
- **Debounce**: Delays function execution until a specified delay has passed **since the LAST event triggered**. (Ideal for Search bar auto-complete, Window resize handlers).
- **Throttle**: Ensures function executes **at most once per specified time interval**, regardless of how many times events trigger. (Ideal for Scroll event listeners, Infinite scroll, Button spamming prevention).

```
Raw Events:   | | | | | | | | | | | | | | | | |
Debounce:     ---------------------------> (Executes 1x after quiet pause)
Throttle:     |----------->|----------->| (Executes strictly every N ms)
```

### 4.2 Production Debounce Implementation
```javascript
function debounce(fn, delay, immediate = false) {
  let timerId = null;

  return function (...args) {
    const context = this;
    const callNow = immediate && !timerId;

    if (timerId) clearTimeout(timerId);

    timerId = setTimeout(() => {
      timerId = null;
      if (!immediate) {
        fn.apply(context, args);
      }
    }, delay);

    if (callNow) {
      fn.apply(context, args);
    }
  };
}

// Usage in DOM Search Input
const handleSearch = debounce((query) => {
  console.log(`API Call for query: ${query}`);
}, 300);
```

### 4.3 Production Throttle Implementation
```javascript
function throttle(fn, limit) {
  let inThrottle = false;
  let lastArgs = null;
  let lastContext = null;

  return function (...args) {
    if (!inThrottle) {
      fn.apply(this, args);
      inThrottle = true;

      setTimeout(() => {
        inThrottle = false;
      }, limit);
    }
  };
}

// Usage in Window Scroll Listener
const handleScroll = throttle(() => {
  console.log(`Scroll position: ${window.scrollY}`);
}, 200);
```
